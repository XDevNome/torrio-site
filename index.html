Questions

Good to know

Is Torrio really free?

Yes. No ads, no paid tier and no account.

Windows says “Windows protected your PC”.

New programs from small publishers can show this SmartScreen message. Click More info, then Run anyway.

My antivirus flagged the setup file.

Some antivirus programs are suspicious of any new installer that sets up file types and browser integration. Torrio contains no malware. If yours objects, allow the file or report it as a false positive to your antivirus vendor.

What does Torrio send over the internet?

Only what you download, plus a check on this website for new versions (you can turn that off in Options). No usage data.

How do I remove it?

Windows Settings › Apps, like any other program. Files you downloaded are never touched.
